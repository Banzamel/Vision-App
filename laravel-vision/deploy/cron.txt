# Vision production cron — Laravel scheduler.
#
# WAŻNE: dodaj zadanie przez UI HestiaCP (NIE przez `crontab -e`),
#        bo Hestia regeneruje crontab usera ze swojej bazy
#        i ręczne wpisy znikną przy najbliższym v-rebuild-cron-jobs.
#
# Kroki w panelu HestiaCP:
#   1. Zaloguj się jako webmaster (lub admin → przejdź na user webmaster)
#   2. CRON → ADD CRON JOB
#   3. Wypełnij pola:
#
#        Minute:        *
#        Hour:          *
#        Day:           *
#        Month:         *
#        Day of Week:   *
#        Command:       /usr/bin/php8.4 /home/webmaster/web/vision.banzamel.pl/private/artisan schedule:run >> /dev/null 2>&1
#
#   4. SAVE
#
# Po zapisaniu Hestia zarejestruje zadanie i automatycznie zaktualizuje crontab.
# Weryfikacja po dodaniu (jako webmaster):
#   crontab -l | grep schedule:run
#
# Co to robi:
#   schedule:run odpala co minutę i sprawdza task definitions w
#   routes/console.php. Aktualnie zarejestrowany task: vision:albums:sync
#   (everyFiveMinutes) — skanuje katalogi kamer pod kątem nowych zdjęć.
